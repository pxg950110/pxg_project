前端登录页设计方案对比

针对 maidc-portal 登录页产出 3 套风格方案。每套均为可交互静态稿（含密码显隐、hover/focus 态、动效）， 点击卡片下方按钮打开完整预览。评审定稿后将方案落地到 src/views/login/LoginPage.vue。

方案A

深色科技风

暗夜蓝黑底 + 霓虹青点缀，左侧旋转数据环与平台指标大屏，右侧深色玻璃拟态登录卡。

  • 科技感强，契合医疗AI平台定位
  • 数据环 / 指标可承载真实运营数据
  • 暗色环境下视觉冲击力最佳
  • 深色运维大屏风格，评审需确认院内接受度

方案B

简洁浅色风

白底大留白的 SaaS 专业风：顶部品牌栏 + 居中登录卡片，克制的品牌色点缀与合规徽标。

  • 清爽专业，最贴近主流 B 端产品
  • 信息密度低，登录路径零干扰
  • 实现与维护成本最低
  • 品牌记忆点相对弱，依赖落地页叙事

方案C

现有风格基线

复刻当前 LoginPage.vue 视觉：左侧深青品牌墙（心电图动效 + 特性卡片），右侧浅色表单，作为对比参照。

  • 医疗行业语境强（心电、合规提示）
  • 已上线验证，团队认知零成本
  • 评审时用于对比其他方案差异
  • 深浅两区色彩对比较强，风格偏传统

评审要点建议

  1. 风格取向：三套方案代表了「科技感（A）→ 专业感（B）→ 行业感（C）」三种取向，建议先定大方向再抠细节。
  2. 品牌叙事：是否需要在登录页承载平台数据/特性介绍（A/C 有品牌区，B 无）。
  3. 合规呈现：审计提示、等保三级、锁定策略等合规信息的呈现位置与强度。
  4. 功能增强（定稿后统一落地）：字段级校验、失败次数/锁定倒计时、图形验证码位、Caps Lock 提醒、记住用户名回填。
  5. 响应式：三套均已处理 ≤960px 断点（隐藏品牌区/卡片自适应），建议同时用手机宽度过一遍。
