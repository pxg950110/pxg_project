# MAIDC 门户 · 深色科技风设计规范

> 2026-09-11 登录页设计评审定稿：**全站 UI 统一采用深色科技风**。
> 基准实现：`design/login/dark-tech.html`（设计稿）与 `src/views/login/LoginPage.vue`（已落地）。
> 后续新增/改版页面（工作台、表格、表单、弹窗、图表等）均需遵循本基调。

## 1. 色板

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面底色（深） | `#060b16` → `#0a1220` | 160° 线性渐变作全局背景 |
| 卡片/面板 | `rgba(15, 26, 46, 0.55~0.72)` | 玻璃拟态：半透明深蓝 + `backdrop-filter: blur(8~18px)` |
| 面板描边 | `rgba(94, 234, 212, 0.12)` / `rgba(148, 163, 184, 0.12)` | 低透明度青/灰细边 |
| 主色（霓虹青） | `#22d3ee` | 主按钮、焦点态、高亮、链接 |
| 辅色（电紫） | `#818cf8` | 渐变收尾色、次级点缀 |
| 主文字 | `#e6edf6` | 深底上的正文/标题 |
| 次文字 | `#94a3b8` | 说明文字 |
| 弱文字 | `#64748b` | 提示、页脚 |
| 输入框底 | `rgba(8, 15, 30, 0.65)` | focus 时加深至 0.9 |
| 输入框描边 | `rgba(148, 163, 184, 0.18)`，hover 0.32 | focus 换主色 |

渐变主按钮：`linear-gradient(135deg, #22d3ee 0%, #38bdf8 55%, #818cf8 100%)`，文字用深色 `#04121e`（不用白字）。
标题强调字：青→紫渐变文字（`background-clip: text`）。

## 2. 几何与质感

- 圆角：卡片 18~20px，输入框/按钮 10~12px，小徽标 999px。
- 阴影：深色大投影 `0 24px 60px rgba(2, 8, 20, 0.6)`；主按钮发光 `0 6px 22px rgba(34, 211, 238, 0.35)`。
- 焦点环：`0 0 0 3px rgba(34, 211, 238, 0.14)` + 外发光。
- 卡片顶部高光线：`linear-gradient(90deg, transparent, rgba(34,211,238,0.5), transparent)`。

## 3. 背景装饰（科技感氛围件）

- 细网格：48px 网格线（白色 4.5% 透明度），径向 mask 渐隐。
- 扫描光带：180px 高、青色 4.5% 透明度，9s 上下巡游。
- 漂浮粒子：3~5px 发光圆点，14s 漂移。
- 数据环（品牌区）：多层旋转虚线/实线圆环 + conic-gradient 光圈 + 呼吸核心。
- 克制原则：一个页面 ≤1 种主装饰 + 网格，避免堆叠导致视觉噪音。

## 4. 动效

- 时长：微交互 0.15~0.25s；氛围动效 4~26s 循环。
- 缓动：`ease-in-out`（氛围）、`linear`（旋转）。
- 所有氛围动效必须包裹 `@media (prefers-reduced-motion: reduce)` 降级。
- hover 抬升：`translateY(-1px)` + 发光增强。

## 5. 组件映射（ant-design-vue 深色化约定）

后续页面使用 `w-*/a-*` 或原生组件时：

- 表格：表头 `rgba(15, 26, 46, 0.8)`，行 hover `rgba(34, 211, 238, 0.06)`，边框 `rgba(148,163,184,0.12)`。
- 弹窗/抽屉：面板色 + 18px 圆角 + 顶部高光线。
- 状态色在深底上的可读版本：成功 `#34d399`、警告 `#fbbf24`、危险 `#f87171`（较浅，保证深底对比度）。
- 图表（ECharts）：底色透明，轴线/分割线用 `rgba(148,163,184,0.15)`，系列色优先青/紫系。

## 6. 反例（禁止）

- 深色页面上使用纯白大面积区块（登录卡以外的白底卡片）。
- 霓虹色作大面积填充（霓虹青只做点缀、描边、光效）。
- 关闭 `prefers-reduced-motion` 降级。
- 页面间色板漂移：新增颜色先对齐本规范或在本文件补录。
